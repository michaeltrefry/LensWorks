# S47 deterministic photographs and native UI tour

The generator creates eight RGB8 PNG photographs from one unsigned 32-bit seed: two single photographs, a three-frame moving-subject exposure bracket, and a three-frame panorama with 48-pixel world-space overlap. It downloads no asset, model, profile, or library. The manifest declares generated pixels CC0-1.0.

Within the bracket, the world-scene seed and all non-subject pixels are stable. The only scene motion is the declared subject rectangle. Exposure is exactly `2^exposure_stops` before RGB8 encoding: the even, unsaturated background uses integer floor division at -1 EV and exact doubling at +1 EV; the foreground uses the declared RGB8 saturation rule. Generator controls decode all foreground and background pixels, including the +1 EV foreground saturation point. Within the panorama, adjacent camera crops retain identical bytes across their declared 48-pixel overlap.

Each of two independent UI launches creates a distinct demo catalog, imports the original generated photographs, opens `single-harbor.png`, and waits for an accessibility marker emitted only when the current selected catalog asset, its working-version source identity, and the active editor document agree. The test expects `single-harbor.png|master|160x120`, retains an editor capture, observes the ordinary public Quit command terminate the app, then rehashes every source original. Each fresh catalog is named `Demo.catalog` within its separately prepared `WorkingVersions-1` or `WorkingVersions-2` folder. After the normal photo route creates its distinct UUID-named working version, the tour uses the ordinary File → Save As… sheet to save `single-harbor.comp` in that same owned folder, outside the catalog directory. It checks the actual saved source record, complete native original and VariantKey, distinct working-version ID, preserved original source record, and current loaded marker before capture. The two retained captures are compared only after both complete tours finish and produce an independently measured maximum channel delta and nonzero-pixel changed fraction.
