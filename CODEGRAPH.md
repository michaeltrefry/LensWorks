## Projects

### LensWorks

LensWorks is a photo/image management and processing system with two primary adapter components: `lensworks-catalog` handles the full decode pipeline for raw/source image files (spawning worker subprocesses, managing decode limits, writing scene output files with integrity checks), and `lensworks-inference` provides an adapter for AI inference requests (captioning, embedding, segmentation via SAM2/SAM3, text generation, and image transformation). The catalog adapter integrates with a `photocatalog` core library for metadata, storage volumes, and media decode orchestration, while the inference adapter defines typed request parameter structs consumed by a capability-checking layer.
